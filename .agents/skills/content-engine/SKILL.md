# Content Engine — Real Estate Marketing

Turn a single property listing into platform-native marketing content for every channel, in both English and Chinese.

## When to Activate

- Generating social media posts from listing data
- Creating ad copy for Google/Meta campaigns
- Writing email campaign content
- Drafting WeChat / 小红书 content
- Repurposing a listing, open house, or deal story across platforms
- Building content calendars for agents

## Source Assets (Real Estate Specific)

| Source | What to Extract |
|--------|----------------|
| New listing | Price, features, location story, neighborhood vibe, photos |
| Price reduction | Urgency angle, value comparison, market context |
| Open house | Event details, neighborhood draw, FOMO angle |
| Just sold | Success narrative, market proof, agent credibility |
| Market data | Trends, insights, educational content |
| Showing feedback | Client reaction → testimonial seed |
| Deal story | Full narrative → trust building content |

## Core Rules

1. **Adapt for the platform** — never cross-post identical copy
2. **Hooks beat summaries** — first line must stop the scroll
3. **One listing = one clear angle** per post (don't list 5 features)
4. **Bilingual is not translation** — rewrite for cultural context
5. **CTA matches the platform** — DM on WeChat, link on email, save on IG

## Platform Guidance

### WeChat 朋友圈
- 9 图格式：首图抓眼球，用美图 + 价格大字
- 文案控制在 6 行以内（折叠前可见）
- 用 emoji 分段，不用 hashtag
- 结尾：加我微信看更多 / 私信了解详情
- 语气：专业但亲切，像朋友推荐

### 小红书
- 封面图：房源美图 + 文字标题叠加
- 标题：数字 + 地名 + 卖点（"$89万 Irvine 学区房 4室3卫"）
- 正文：分段短句，用 emoji 做 bullet
- 标签：#北美买房 #学区房 #尔湾 等
- 语气：种草体，分享型

### Instagram / Facebook
- Lead with best photo (hero shot)
- Caption: neighborhood story > feature list
- Carousel: 5-7 images with story arc (exterior → living → kitchen → view)
- Hashtags: 15-20 mixed (local + general)
- CTA: "Link in bio" or "DM for details"

### Email Campaign
- Subject line: specific + urgent ("Just listed: 4BR in Irvine Spectrum — $1.2M")
- Preview text: the hook that doesn't repeat subject
- Body: hero image → 3 key features → neighborhood brief → CTA button
- Bilingual: full Chinese section below English, not inline translation

### Google/Meta Ads
- Headline: 30 chars max, feature + location ("4BR Irvine Home | $1.2M")
- Description: benefit-oriented ("Top-rated schools, 10 min to UCI")
- Image: exterior photo, no text overlay (Meta policy)
- CTA: "Schedule Showing" / "View Details" / "预约看房"

### TikTok / Reels (Short Video)
- First 3 seconds: the money shot (view, kitchen, pool)
- Script structure: hook → walkthrough → surprise → CTA
- Text overlay: price, address, key stat
- 15-30 seconds optimal
- Music: trending + appropriate

## Repurposing Flow

```
New Listing (source)
  ├─→ WeChat 朋友圈 (9 图 + 6行文案)
  ├─→ 小红书 (封面图 + 种草体文案)
  ├─→ Instagram post (carousel + EN caption)
  ├─→ Email blast (bilingual, hero image)
  ├─→ Google/Meta ad (headline + description)
  └─→ AI Video (Sora/即梦 from listing photos)
```

For each platform, extract different angles:
1. **Location story** — neighborhood, schools, commute
2. **Lifestyle angle** — who would love living here
3. **Investment angle** — appreciation, rental potential
4. **Value angle** — price comparison, what you get for the money
5. **Urgency angle** — market heat, competing offers

## Bilingual Content Rules

**DO NOT translate — rewrite:**

| English angle | Chinese angle |
|---|---|
| "Great schools nearby" | "学区房，Greatschools 评分 9/10" |
| "Open floor plan" | "大开间客厅，南北通透" |
| "Investment opportunity" | "投资自住两相宜，租金回报率 X%" |
| "Minutes from downtown" | "10分钟到华人超市，生活便利" |

Chinese buyers care about different things:
- 学区 (school district ratings)
- 朝向 (house orientation / feng shui)
- 华人社区 (Chinese community proximity)
- 超市/餐馆 (Chinese grocery/restaurant access)
- 新房 vs 老房 (year built is important)

## Quality Gate

Before delivering any content:
- [ ] Each draft reads natively for its platform
- [ ] Hook is specific (not "Beautiful home for sale!")
- [ ] No generic hype ("Don't miss this amazing opportunity!")
- [ ] Chinese content is culturally adapted, not machine-translated
- [ ] CTA matches platform behavior
- [ ] Agent branding is consistent across all outputs
- [ ] Photo/image specs match platform requirements

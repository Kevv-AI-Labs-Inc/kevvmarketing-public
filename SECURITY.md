# Security Policy

## Supported Scope

Security reports are welcome for:

- authentication and session handling
- OAuth and magic-link flows
- API authorization and data exposure
- secret handling and configuration leaks
- SSR / route behavior that could expose private data
- hosted deployment behavior at `marketing.kevv.ai`

## How to Report a Vulnerability

Do not open a public GitHub issue for security vulnerabilities.

Report privately to:

- `support@kevv.ai`

Include:

- a clear description of the issue
- affected routes, files, or flows
- reproduction steps
- impact assessment
- any proof-of-concept details needed to validate the report

If the issue involves credentials or private customer data, do not include real secrets or real user data in the report unless explicitly requested through a secure channel.

## Response Expectations

We will triage reports and determine:

- whether the issue is valid
- severity and exposure
- remediation approach
- disclosure timing

## Disclosure Policy

Please allow time for remediation before any public disclosure.

If we confirm a valid issue, we will fix it and then coordinate any public note if needed.
